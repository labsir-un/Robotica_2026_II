## ✅ Reglas básicas

1. Edita **solo** la carpeta de tu grupo o de tu equipo.
2. Conserva un `README.md` como informe principal.
3. Usa rutas relativas para los recursos.
4. Evita subir archivos temporales o duplicados.
5. Antes de comenzar, ejecuta `git pull`.

## 🧪 Flujo sugerido

```bash
git pull
git status
git add .
git commit -m "Actualizar documentación"
git push
```

## ⚠️ Evita

- modificar carpetas de otros grupos;
- subir carpetas personales del sistema;
- borrar archivos compartidos sin confirmación.
