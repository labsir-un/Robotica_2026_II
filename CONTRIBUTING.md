# Contribuciones — Robótica 2026-II

Este repositorio es compartido por los grupos del curso.

## Reglas de trabajo

1. Modifica únicamente la carpeta de tu grupo de laboratorio o de tu equipo de proyecto final.
2. Antes de comenzar, ejecuta `git pull`.
3. No elimines ni renombres carpetas de otros grupos.
4. Cada laboratorio debe conservar un `README.md` como informe principal.
5. Usa rutas relativas para imágenes y archivos incluidos en el repositorio.
6. Evita subir archivos temporales, cachés, entornos virtuales, compilados o archivos de gran tamaño que no sean necesarios.
7. Escribe mensajes de commit breves y descriptivos.

## Ejemplo

```bash
git pull
git add .
git commit -m "Lab 04 - Informe Turtlesim grupo 2B"
git push
```

Si Git informa un conflicto, no fuerces el `push`. Resuelve primero los cambios remotos y verifica que no estés sobrescribiendo el trabajo de otro grupo.
