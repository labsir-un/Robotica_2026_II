## Documentación del proyecto

Este `README.md` debe utilizarse como punto de entrada de la documentación del proyecto final.

Se recomienda organizar el contenido, cuando aplique, en:

- descripción del problema;
- objetivos;
- diseño de la solución;
- simulación;
- programación;
- implementación en el robot real;
- resultados;
- evidencias;
- conclusiones;
- referencias.

Los archivos adicionales pueden organizarse en subcarpetas como `media/`, `src/`, `code/`, `docs/` o las que el equipo necesite.
