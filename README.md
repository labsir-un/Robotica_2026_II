> Este repositorio centraliza el material del curso, la organización de los grupos de laboratorio y la documentación del proyecto final. Su estructura está diseñada para que cada grupo trabaje en su carpeta sin interferir con el trabajo de los demás.

## ✨ Contenido principal

- **`Profesor/`**: material y guías del curso.
- **`Estudiantes/`**: carpetas individuales por grupo con sus laboratorios.
- **`Proyecto_Final/`**: equipos del proyecto final y su documentación.
- **`docs/`**: tablas actualizadas de integrantes en formato imagen y PDF.

## 🚀 Flujo recomendado de trabajo

```bash
git pull
git status
git add .
git commit -m "Actualizar informe del laboratorio"
git push
```

## 📌 Recomendaciones

- Trabajar **solo** dentro de la carpeta de su grupo o equipo.
- Mantener `README.md` como punto de entrada del informe.
- Usar rutas relativas para imágenes, videos y archivos.
- No subir archivos temporales o innecesarios.
